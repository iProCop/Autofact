# 4. План реализации (уроки)

**Версия:** 1.1  
**Дата:** 22 июля 2026  

## Кто где работает

| Папка | Роль |
|-------|------|
| **`autofact-learn/`** | Эталон. **Не трогаем** (ни агент, ни правки ради учёбы). Смотреть / запускать — можно. |
| **`autofact-solo/`** | **Ты** собираешь с нуля по урокам → свой готовый проект. |
| **`discussion/lessons/`** | Агент пишет уроки **максимально подробно** (зачем, где, что писать). Потом проверяет твой solo. |

**Правила:** агент не пишет код в `solo` за тебя; `learn` не меняем.

Оценка: **~30–50 вечеров** до MVP.

---

## Правила учёбы

1. Читаешь подробный урок → делаешь **только в solo**.  
2. Подглядеть в learn можно; копировать проект целиком — нет.  
3. Один урок = одна цель. Чеклист `[x]` ставишь сам.  
4. В чат: «готово» / вопрос / ошибка → агент проверяет.  
5. Офлайн: `lessons/` + эталон на флешке (`3_DEVICES_AND_OFFLINE.md`).

Старт: [`lessons/00_START_HERE.md`](./lessons/00_START_HERE.md)
