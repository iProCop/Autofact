## Зачем

Понять, где эталон, где твоя работа, и что инструменты установлены.

## Теория

- **`autofact-learn`** — эталон (агент уже собрал). **Не трогаем.** Смотреть/запускать можно.  
- **`autofact-solo`** — ты пропускаешь всё через себя → в конце свой готовый проект.  
- **Уроки** (`discussion/lessons/`) — агент пишет максимально подробно; ты делаешь; агент проверяет.  
- **Node.js** — запускает Nest/Next.  
- **Docker** — Postgres + Redis без ручной установки.  
- **api** — сервер (логика, БД).  
- **web** — то, что видит пользователь в браузере.

## Что сделать тебе (в `autofact-solo`)

### 1. Проверь инструменты

```powershell
node -v
npm -v
docker -v
docker compose version
```

### 2. Создай каркас папок

В `C:\AutoFact\autofact-solo\`:

```
autofact-solo/
  apps/
    api/       ← пусто пока
    web/       ← пусто пока
  README.md    ← своими словами: «моя сборка AutoFact с нуля»
```

Файл `docker-compose.yml` — на **Уроке 1**, не раньше.

### 3. (Опционально) Запусти эталон, чтобы увидеть цель

```powershell
cd C:\AutoFact\autofact-learn
docker compose up -d
# дальше по README эталона — api + web
```

Эталон можно не трогать, если не хочешь — главное понять, что он есть.
